This directory contains **representative sample output** demonstrating the expected format and structure of diagnostic artifacts generated by the Prosper Diagnostics Platform.

## Important Notes

### Representative Data

The files in this directory show the **expected schema and structure** of diagnostic output. They contain:

- **Realistic values** based on typical Unity/IL2CPP title boot sequences
- **Correct field names and types** matching the diagnostics output specification
- **Proper JSON structure** that validates against the expected schema

### Sample Data Indicators

Some fields contain example/placeholder values for documentation purposes:

- `hash_sha256`: Uses placeholder pattern (`a1b2c3d4...`) for illustration
- NIDs in stubbed imports: Example values (`0xAABBCCDD`) showing format
- Event IDs: Abbreviated sequence (20 events shown, `total_count` indicates full set)

These placeholders are **clearly identifiable** and do not represent actual captured data.

### Actual Runtime Output

When running `./prosper-app --diagnostics --ai-report <PPSA02929>`, the real output will contain:

- Actual SHA256 hashes of the executable
- Real NID values from the title's import table
- Complete event log (all 1,247+ events, not abbreviated)
- Precise timing measurements from the actual run
- Real memory addresses and module sizes
